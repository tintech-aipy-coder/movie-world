# 🎬 Movie World | Telegram Mini App

Movie World is a **Telegram Mini App** and intelligent movie assistant powered by the **TMDB API**. It allows users to search for movies and TV shows, explore detailed information, save favorites, and access subtitle links directly inside Telegram.

---

## ✨ Features

- 🔍 Fast movie & TV show search
- 🎬 Detailed movie and TV information
- ⭐ TMDB ratings
- 👥 Cast and crew information
- 🎭 Genres
- 📅 Release year
- 📝 Plot overview
- 🔥 Trending & popular titles
- 🎲 Random movie recommendation
- 🎞️ Now Playing & Upcoming releases
- 📂 Browse by genre
- ❤️ Personal playlist
- 🤖 AI-powered movie recommendations
- 🇮🇷 Persian subtitle links
- 📱 Fully optimized Telegram Mini App interface

---

## 🔐 Security

User security is one of the highest priorities of this project.

The application includes multiple security layers to ensure a safe experience:

- ✅ Official Telegram Mini App InitData verification
- ✅ HMAC signature validation
- ✅ Protection against forged requests
- ✅ Secure Telegram Webhook verification
- ✅ Protected admin endpoints
- ✅ API keys stored only as Cloudflare Secrets
- ✅ No sensitive API keys or tokens exposed to clients
- ✅ Constant-time secret comparison to prevent timing attacks
- ✅ Secure error handling without exposing sensitive information
- ✅ All sensitive operations are processed server-side
