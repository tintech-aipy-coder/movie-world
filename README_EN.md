🎬 دنیای فیلم | Telegram Mini App

دنیای فیلم یک Telegram Mini App و ربات هوشمند جستجوی فیلم و سریال است که با استفاده از TMDB API اطلاعات کامل فیلم‌ها و سریال‌ها را نمایش می‌دهد و امکان جستجوی سریع، مشاهده جزئیات، ذخیره در لیست شخصی و دریافت لینک‌های زیرنویس را فراهم می‌کند.

🔐 امنیت

امنیت کاربران یکی از مهم‌ترین بخش‌های این پروژه است.

این پروژه از چندین لایه امنیتی استفاده می‌کند:

✅ اعتبارسنجی رسمی Telegram Mini App (initData)
✅ بررسی امضای HMAC طبق استاندارد تلگرام
✅ جلوگیری از جعل درخواست کاربران
✅ محافظت از Webhook با Secret اختصاصی
✅ محافظت از پنل مدیریت با Admin Secret
✅ ذخیره Tokenها فقط در محیط امن Cloudflare Workers
✅ عدم قرار گرفتن API Key در سمت کاربر
✅ استفاده از مقایسه Constant-Time برای جلوگیری از حملات Timing Attack
✅ محدود کردن زمان درخواست‌ها (Timeout)
✅ مدیریت خطاها بدون افشای اطلاعات حساس

تمام اطلاعات حساس فقط در سمت سرور پردازش می‌شوند و هیچ API Key یا Token محرمانه‌ای در مرورگر کاربر قرار نمی‌گیرد.
