🎬 Movie World | Telegram Mini App

Movie World is a Telegram Mini App and smart movie assistant powered by TMDB API. It allows users to search movies and TV series, browse detailed information, save favorites, and access subtitle links directly inside Telegram.

.🔐 Security

**Security is one of the project's highest priorities.

This project includes multiple protection layers:

✅ Official Telegram Mini App InitData verification
✅ HMAC signature validation
✅ Protection against forged requests
✅ Secure Telegram Webhook verification
✅ Protected admin endpoints
✅ API keys stored only as Cloudflare Secrets
✅ No sensitive tokens exposed to the client
✅ Constant-time secret comparison
✅ Request timeout protection
✅ Safe error handling without leaking sensitive information

All sensitive operations are processed server-side, ensuring that API keys and secrets never reach the client.
